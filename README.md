# Credit Card Analytics Dashboard

## Project Overview

Project ini merupakan dashboard analisis data kartu kredit yang
dikembangkan menggunakan Google Looker Studio untuk memvisualisasikan
performa transaksi, karakteristik pelanggan, penggunaan kartu,
pendapatan, dan risiko kredit.

## Objectives

- Menganalisis performa transaksi kartu kredit
- Menganalisis karakteristik pelanggan berdasarkan kategori kartu
- Menganalisis pola penggunaan kartu dan jenis pengeluaran
- Menganalisis interest earned dan delinquency
- Menyajikan hasil analisis dalam dashboard interaktif

## Dataset

Dataset berisi informasi mengenai pelanggan, kategori kartu,
transaksi, credit limit, revolving balance, utilization ratio,
interest earned, annual fees, delinquent account, penggunaan chip,
dan expense type.

## Tools

- Google Looker Studio
- Google Sheets/CSV
- Data Visualization

## Dashboard

Dashboard terdiri dari empat halaman:

1. Overview
2. Customer & Card Analysis
3. Transaction & Usage
4. Revenue & Risk

## Key Metrics

- Total Customers
- Total Transaction Amount
- Total Transaction Volume
- Interest Earned
- Delinquency Rate
- Average Credit Limit
- Average Utilization Ratio
